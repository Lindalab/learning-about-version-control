# learning-about-version-control
Learning about Version Control 

Author: Linda Arthur


Solving merge conflicts takes conscious effort, but I can do it!

What I like most about version control is that I can track the work I have done over time and see my progress and improvement. 

What I find most challenging is understanding how Git, GitHub, and branching work together, especially when creating branches, merging changes, and keeping track of where my work is.
